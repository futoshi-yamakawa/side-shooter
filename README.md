# NEON VANGUARD (side-shooter)

ブラウザで動く横スクロールシューティングです。全3ステージ、各ステージ最後にボス戦があります。Phaser 3 + TypeScript + Vite で作っています。

## 遊び方

| 操作 | キーボード | ゲームパッド |
| --- | --- | --- |
| 移動 | 矢印キー / WASD | 左スティック / 十字キー |
| ショット（押しっぱなし） | Z / Space | A |
| パワーアップ（ゲージ選択） | C | X（Yでも可） |
| ボム | X | B |
| 低速移動（当たり判定表示） | Shift | RB / LB / RT / LT |
| ポーズ | Esc / P | START |

### スマホ（タッチ操作）

横向きで遊びます。縦向きにすると案内が出て、ゲームは自動でポーズします。

- 画面のどこかを指でなぞると自機が同じ方向に動き、触れている間は自動連射
- 右下の大ボタンでパワーアップ、その上のボタンでボム、右上の II でポーズ
- 移動は指の位置ではなく移動量に追従するため、指で自機が隠れない

ゲームパッドは Logitech F310 で、背面スイッチの X（XInput）と D（DirectInput）どちらのモードにも対応しています。ブラウザの仕様で、ページを開いた後にパッドのボタンを一度押すまでパッドは認識されません。

### ステージ

| ステージ | 舞台 | 特徴 | ボス |
| --- | --- | --- | --- |
| 1 NEON OUTSKIRTS | ネオンの荒野 | 地形なし、編隊中心 | HEXA-GARGANT（2形態） |
| 2 CRYSTAL CAVERN | 結晶の洞窟 | 天井と床の地形、地上砲台 | BARRIER CORE（バリア3枚の奥にコア） |
| 3 ORBITAL FORTRESS | 軌道要塞 | ブロック状の地形、機雷 | OVERMIND（4つの砲台を壊すと目が開く） |

地形に触れるとミスです（ガードでも防げません）。ボスを倒すと得点・残機・装備を持ったまま次のステージへ進みます。

### パワーアップゲージ（グラディウス方式）

編隊を全滅させるか大型機を倒すとオレンジのカプセルが出ます。取るたびに画面下のゲージが1つ右へ進み、パワーアップボタンで点灯中の項目を取得します。取得するとゲージは空に戻ります。

| ゲージ | 効果 | 最大 |
| --- | --- | --- |
| POWER | ショット強化。拡散ショットは4段階目で主砲が太く、5段階目で6方向＋分身2連射。レーザーは段階ごとに太く強く | 5段階 |
| MISSILE | ミサイル。地形に沿って這う。2段階目で上方向にも発射 | 2段階 |
| LASER / SPREAD | 拡散ショットとレーザー（貫通）を切り替え | - |
| OPTION | 分身（自機の軌跡を追いかけて同じ武器を撃つ） | 3体 |
| GUARD | ガード（弾や敵の被弾を1回防ぐ） | 1 |
| BOMB | ボム追加 | 5個 |

最大まで取った項目は暗く「MAX」と表示され、選べません。ミスするとショット1段階、ミサイル1段階、分身1体と、点灯中のゲージを失います。

### 残機の増え方

- 各ステージで2機目に倒した大型機（キャリア）が緑の1UPカプセルを落とす
- 10万点、30万点、以降30万点ごとにエクステンド
- 残機は最大9。上限時の1UPは1万点

## ローカルで動かす（Mac）

```sh
npm install
npm run dev
```

表示された `http://localhost:5173/` をブラウザで開きます。

確認用のURLパラメータがあります。

- `?stage=2` ステージ2から開始（1〜3）
- `?boss` そのステージのボス戦から開始（パワー最大）
- `?t=30` ステージを30秒地点から開始

## 構成

- `src/scenes/` Boot（画像生成とフォント待ち）、Title、Game
- `src/entities/` 自機と分身、敵6種、カプセル、弾プール
- `src/entities/bosses/` ボス3体（共通インターフェースは `types.ts`）
- `src/systems/controls.ts` キーボードとゲームパッドの入力をまとめる
- `src/stage/stages.ts` 3ステージの定義（背景、地形、BGM、敵の出現タイムライン、ボス）
- `src/systems/terrain.ts` 天井と床の地形（高さマップのスクロールと当たり判定）
- `src/systems/juice.ts` ヒットストップ、スロー、画面揺れ、フラッシュ
- `src/systems/fx.ts` 爆発、火花、破片、衝撃波リング
- `src/systems/audio.ts` 効果音とBGMをWeb Audioで合成
- `src/systems/textures.ts` 全グラフィックをCanvasで描画生成

画像・音声ファイルは使っていません。すべて実行時にコードで生成しているため、素材ライセンスの制約がありません。
