# NEON VANGUARD (side-shooter)

ブラウザで動く横スクロールシューティングの試作です。Phaser 3 + TypeScript + Vite で作っています。

## 遊び方

| 操作 | キーボード | ゲームパッド |
| --- | --- | --- |
| 移動 | 矢印キー / WASD | 左スティック / 十字キー |
| ショット（押しっぱなし） | Z / Space | A（Xでも可） |
| ボム | X / C | B（Yでも可） |
| 低速移動（当たり判定表示） | Shift | RB / LB / RT / LT |
| ポーズ | Esc / P | START |

ゲームパッドは Logitech F310 で、背面スイッチの X（XInput）と D（DirectInput）どちらのモードにも対応しています。ブラウザの仕様で、ページを開いた後にパッドのボタンを一度押すまでパッドは認識されません。

### アイテム（ベル方式）

編隊を全滅させるか大型機を倒すとカプセルが出ます。カプセルは撃つと跳ね上がり、6発当てるごとに種類が変わります。

| 表示 | 効果 | 最大 |
| --- | --- | --- |
| P | ショット強化 | 3段階 |
| O | 分身（自機の軌跡を追いかけて一緒に撃つ） | 3体 |
| S | スピードアップ | 3段階 |
| G | ガード（被弾を1回防ぐ） | 1 |
| B | ボム追加 | 5個 |

最大まで取ったアイテムは5000点になります。ミスするとショット1段階、分身1体、スピードを失います。

## ローカルで動かす（Mac）

```sh
npm install
npm run dev
```

表示された `http://localhost:5173/` をブラウザで開きます。

確認用のURLパラメータがあります。

- `?boss` ボス戦から開始（パワー最大）
- `?t=30` ステージを30秒地点から開始

## 構成

- `src/scenes/` Boot（画像生成とフォント待ち）、Title、Game
- `src/entities/` 自機と分身、敵3種、中ボス、カプセル、弾プール
- `src/systems/controls.ts` キーボードとゲームパッドの入力をまとめる
- `src/stage/stage1.ts` 敵の出現タイムライン（秒単位のデータ）
- `src/systems/juice.ts` ヒットストップ、スロー、画面揺れ、フラッシュ
- `src/systems/fx.ts` 爆発、火花、破片、衝撃波リング
- `src/systems/audio.ts` 効果音とBGMをWeb Audioで合成
- `src/systems/textures.ts` 全グラフィックをCanvasで描画生成

画像・音声ファイルは使っていません。すべて実行時にコードで生成しているため、素材ライセンスの制約がありません。
